# SANG — Military Command Website

Responsive statische Website für GitHub Pages.

## Dateien
- `index.html` — Seiteninhalt
- `style.css` — Design und mobile Darstellung
- `script.js` — aufklappbare Dienstordnung, Suche und mobile Navigation
- `assets/military-base.png` — bereitgestelltes Bild der Militärbasis

## Lokal ansehen
Öffne `index.html` im Browser.

## Auf GitHub veröffentlichen
1. Erstelle ein Repository auf GitHub
2. Entpacke diese ZIP-Datei und lade alle Dateien inklusive `assets` hoch
3. Öffne **Settings → Pages**
4. Wähle **Deploy from a branch**, Branch `main`, Ordner `/ (root)`
5. Speichern und warten, bis GitHub Pages die Seite veröffentlicht

Die Website ist statisch und enthält kein Login- oder Datenbanksystem.
